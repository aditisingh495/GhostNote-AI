# 👻 GhostNote AI

Some stories refuse to disappear.

GhostNote AI is a spooky, memory-keeping web experience inspired by Día de los Muertos.
You leave a thought in the dark, and an open-weight AI turns it into a haunting, unforgettable story.

### Why Open AI?
- Uses an open-weight model (DeepSeek) - not a closed paid API
- Keeps personal memories private, can run locally
- Free to run, model can be swapped anytime

### How to Run
1. Open index.html in your browser
2. Type your thought / memory
3. Click the ghost to get your story
